# 我的 RSM 实验助手

面向实验人员的中文响应面法（RSM / Box-Behnken 设计）优化助手。
定位：**不是替代 Design-Expert，而是把你真正会用到的那一小部分流程做得更顺手。**

一句话：**单因素定范围，BBD 看组合；模型找最优，实验做验证。**

## 正确性验证（两个公开文献数据集）

`validate_public.py` 用两篇开放获取论文的完整 BBD 数据做端到端验证：

```bash
python validate_public.py
```

- **数据集一**：Sharma 2014, *BioMed Research International*, PMC4122152 —— 4 因素 PLGA 纳米粒，
  26 个实验（粒径 + 包封率）
- **数据集二**：*Scientific Reports* 2022, s41598-022-12642-2（Nature 旗下）——
  3 因素植物多酚提取，17 个实验（产率 + 总多酚）

验证强度：所有统计量先由 statsmodels 公式 API（独立代码路径）精确复核；数据集二
做到**逐系数对照**（9 项系数、R²、调整 R²、预测 R²、失拟 P 全部与论文
Design-Expert 数值吻合，软件寻优结果与论文最优点编码距离 0.01~0.07）；数据集一
论文报告值为精简模型口径，报告中已注明。另覆盖报错路径：缺结果拟合、因素不足、
不可配制条件、Excel 往返。报告见 `output/公开数据验证报告.txt`，图见 `output/*.html`。

## 一键载入示例实验（测试用）

双击 **`打开示例实验.bat`** 会弹出编号菜单让你选示例（直接回车 = 产率）；或命令行 `python demo_launch.py yield`：
公开文献的真实 BBD 数据，因素、设计、全部实测结果都已填好，点「下一步」即可走完
拟合 → 响应面 → 寻优 → 验证 全流程。可选参数：`yield`（3 因素产率，**默认**，
模型质量好：R²=0.99、信噪比 13.8）、`tpc`（同一论文的总多酚响应，检测噪声大，
专门用来看"弱模型警告"长什么样）、`ee` / `size`（4 因素 PLGA）。示例不进软件界面，
正常实验用 `启动助手.bat` 打开即是空白实验。

## 快速开始

```bash
# 首次使用：安装依赖（已装过可跳过）
pip install -r requirements.txt

# 启动
python main.py
```

Windows 下也可以直接**双击 `启动助手.bat`**。

## 软件流程（对应左侧五步）

| 步骤 | 你要做的 | 软件自动做的 |
|---|---|---|
| ① 新建实验 | 填实验名称、响应指标、优化目标、各因素的低/中心/高水平 | 处理编码水平等统计学细节 |
| ② 设计实验 | 检查配液设置（总体积、固定组分、母液浓度） | 生成 BBD → 换算实际取值 → 随机化运行序 → 加中心点 → **逐个检查能不能配出来** |
| ③ 输入结果 | 按「运行序」填实测响应值（支持 Excel 导入 / 剪贴板粘贴） | 保存、统计完成度 |
| ④ 分析模型 | 点「拟合模型」，看汇总表 + 各项检验 + 内置解读 | statsmodels 本地计算：模型 F/P、各 terms 偏检验、R²/调整R²/预测R²、失拟检验、信噪比；绘制可旋转的 3D 响应面与等高线（Turbo 论文风配色，另有 Viridis/Cividis/Jet/蓝-白-红可选） |
| ⑤ 最优条件与验证 | 点「寻找最佳条件」→ 实际做验证实验 → 填实测值 | 数值寻优（scipy）→ **配液可行性检查**（不可配制时可在约束下重新寻优）→ 计算相对误差、记录验证 |

菜单「项目」可打开/保存实验、导出**实验记录 Markdown**（含设计表、ANOVA、最优条件、验证记录，可直接进实验档案）。

## 工具：摩尔浓度 / 稀释 / 摩尔质量计算器

菜单「工具」（快捷键 Ctrl+L），做实验时可常开（非模态窗口）：

- **摩尔浓度** c = m/(M·V)：质量 / 摩尔质量 / 体积 / 浓度，选要求哪项、填其余三项；
  质量（g/mg/μg）、体积（L/mL/μL）、浓度（M/mM/μM/nM）单位可换算，结果自动回填
- **稀释** C1V1 = C2V2：知三求一，并给出操作提示
  （"吸取 V1 储备液，加稀释液定容至 V2"）和稀释倍数

（摩尔质量 M 请查试剂瓶标签；计算器不解析化学式。）

## 固定总体积体系（配液检查）—— 本软件的特色

针对"总体系 50 μL、DNA 固定 20 μL、其余由水补足"这类体系：

- 每个因素可选三种加入方式：**不参与 / 按体积(μL)直接加入 / 按母液浓度换算**
  （换算：加入体积 = 因素取值 × 总体积 ÷ 母液浓度）
- 生成设计后，软件逐个实验计算各因素加入体积和补足液体积：
  - 水 ≥ 0 且各体积 ≥ 最小可移液体积 → **✓ 可执行**
  - 否则 → **⚠ 无法配制**（统计学上成立 ≠ 实验上可执行）
- 预测最优条件同样检查；若无法配制，点「在可执行范围内重新寻优」，
  软件在"补足液够用、体积可移液"约束下重新找最优。

固定总体积 ≠ 混合物设计：只有当 A+B+C 本身是必须满足固定比例的研究对象时，才需要 mixture design。

## AI 助手（右侧面板）

- 分工边界：**统计量全部由本地 statsmodels/scipy 计算；AI 只把结果翻译成人话，不发明统计方法。**
- AI 读取：`skills/rsm_skill.md`（实验大脑说明书）+ 当前实验数据 + 软件计算结果。
- 未配置 API 时可点「内置解读」：由统计结果直接生成的确定性白话解读（离线可用）。
- 配置：点面板「设置」，填写兼容 OpenAI `/chat/completions` 的接口。
  **推荐本地小模型**（免费、实验数据不出电脑），两种任选：
  - **LM Studio**（图形界面，适合已有软件的用户）：打开 LM Studio → 顶部
    **Developer（开发者）** 页签 → 加载一个对话模型 → 点 **Start Server**（保持运行）→
    回本软件设置里点「填入 LM Studio 默认」→ 点「获取服务里的模型列表」→ 下拉选模型 → 确定。
  - **Ollama**（命令行）：安装后运行 `ollama pull qwen2.5:7b-instruct`，点「填入 Ollama 默认」。
  本地服务无需真实 API Key（随便填）。云端（DeepSeek、通义、Kimi）也照样支持。
  配置保存在 `config.json`（含 API Key，勿外传）。

想改软件的行为逻辑（实验流程、判断标准），直接编辑 `skills/rsm_skill.md`，重启生效。

**响应面配色**：Plotly 配色没有锁定。默认 Viridis（Nature 期刊常用，色盲友好）；
第四步绘图区可切换 Cividis、Turbo（蓝→绿→黄→红论文风）、Jet、蓝-白-红发散色。
3D 图带表面白色网格线与地面投影等高线，实验点直接标注在图上。

## 第一版明确不做的事

几十种 DOE、混合物设计、工业约束、多响应优化、用户账户、云端同步、团队协作 ——
都不在本版。第一版只做：**3~5 因素 BBD → 实验表 → Excel → 二次模型 → ANOVA →
响应面 → 最优条件 → 验证。** 用几次觉得哪里不顺手，再让 AI 改。

## 统计口径（给较真的你）

- 回归在**编码变量**上进行；各项 P 值为完整模型下的偏检验（与 Design-Expert 的
  Adjusted 检验一致，F = t²）
- 预测 R² = 1 − PRESS/SST，PRESS 由帽子矩阵对角元计算
- 失拟检验以重复设计点（中心点）为纯误差
- Adequate Precision = 预测值极差 / √(p·MSE)，> 4 表示模型可用于导航设计空间
- 寻优：网格多起点 + L-BFGS-B；约束寻优用 SLSQP

漂亮响应面 ≠ 模型可靠；最终以验证实验为准。
